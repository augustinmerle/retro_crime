# 🔎 Retro Crime Board

Board collaboratif temps réel pour rétro sprint format "Crime Investigation".

## Deploy sur Railway (2 min)

1. Push ce repo sur GitHub
2. Va sur [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo**
3. Sélectionne ce repo → Railway détecte automatiquement Node.js
4. C'est tout ! Railway te donne une URL publique à partager à ton équipe

## Lancer en local

```bash
npm install
npm start
# → http://localhost:3000
```
